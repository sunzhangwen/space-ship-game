# Alien Invasion

A 2D space shooting game built with Python and Pygame.

## Gameplay

- Control a spaceship at the bottom of the screen
- Move left/right/up/down with arrow keys
- Fire bullets with **Space**
- Press **Q** to quit

## Getting Started

```bash
pip install -r requirements.txt
python alien_invasion.py
```

## Project Structure

```
alien_invasion.py   # Game entry point and main loop
settings.py         # Game configuration (screen, speed, bullets)
ship.py             # Player's spaceship
bullet.py           # Bullet sprite
images/             # Game assets (ship.bmp, hero.bmp)
```
